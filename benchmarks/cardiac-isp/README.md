# Reproducing a cardiac in silico perturbation

Use this benchmark to test whether a fixed model reproduces a published perturbation and whether a second model transfers the direction on the same nuclei. GSN deletion in dilated cardiomyopathy (DCM) is the reference case. A second track tests allele-to-expression prediction in ventricular tissue. The reference paper reports a pooled screen. The donor-level joint criterion below is a proposed extension. [Original study, Fig. 6](https://pmc.ncbi.nlm.nih.gov/articles/PMC10949956/) · [Public heart atlas, D4](../../docs/DATASETS.md)

## What to fix before inference

| Question | Recommended primary design | Evidence to retain |
|---|---|---|
| Can this implementation replay the original? | Released disease-fine-tuned Geneformer V1-10M, author-ranked tokens, original training donor list, original gene pooling and state references. Delete GSN. | Checkpoint and tokenizer hashes, reference IDs, library revision, reference and perturbed scores, tolerances. |
| Does the direction transfer to V2-104M or scGPT? | Same corrected-count nuclei, donor partitions, reference-cell identities, cell weights, GSN and control genes by stable ID. Use each model's own embedding coordinates. | Native sequence limits, readout, exact same-cell intersection, missing controls, unforced target retention, cell and donor counts. |
| Does training scale matter? | Keep the base checkpoint and recipe within model. Compare the bounded fit with all eligible training nuclei. Choose the epoch on donor-held-out disease validation alone. | Unique training exposures per epoch, split hash, held-out donor predictions and balanced accuracy. Evaluate GSN after locking the checkpoint. |
| Does a DNA allele predict measured cis-expression direction? | AlphaGenome 2 on public GRCh38 REF and ALT in a fixed ventricular condition, window, checkpoint, scorer and primary assay track. One primary allele per locus. | Score reconstruction, strand/ALT harmonization, comparison study and uncertainty, selection provenance, missing pairs and training-region overlap. |

For a Geneformer classifier, retain the source count layer, per-gene normalization, vocabulary, sequence order, special tokens and the pooling layer. For scGPT, pin the vocabulary, feature order before sampling, expression bins and random seed. On a small set, compare actual ordered token IDs and values against the reference implementation. In each nucleus keep the other genes fixed between GSN and control edits. Distinguish masking, physical deletion and changing the expression value. If target retention is forced, report its frequency in the unforced context and the result on naturally retained targets. For a paired comparison, use the same available comparison gene identities in both models and recompute both baselines; give counts of cells with zero, partial and complete control sets. Equal cell counts or donor labels alone do not establish identical nuclei.

## Reference values and decision rules

1. **Technical replay.** In Supplementary Table 12, worksheet DCM_del_tx, the GSN row (ENSG00000148180) reports 315 detections, pooled shift +0.03230355 toward non-failing heart (NF) and −0.09919650 toward hypertrophic cardiomyopathy (HCM). Compare pooled raw scores to these numbers only under the corresponding estimand. If the exact 315 identities or sampler are unavailable, mark exact numeric replay unavailable and report the observed denominator and deviations. A 9/9 donor criterion is a different estimand. [Published table](https://static-content.springer.com/esm/art%3A10.1038%2Fs41586-023-06139-9/MediaObjects/41586_2023_6139_MOESM15_ESM.xlsx)
2. **Numerical resolution.** Recompute identical unedited inputs independently, repeat a saved edit and validate a hand-checked deletion against the native kernel. Register the precision-specific tolerance and minimum interpretable effect before viewing target results. Check that the reference vectors are distinguishable. Report no-op and replay discrepancies beside the shifts. Keep existing registered study gates. [Repository criteria](../../docs/CRITERIA.md)
3. **Cell-model endpoint.** For each nucleus compute the change in cosine similarity after deleting GSN, then subtract the mean change from its registered controls. Average within donor and give donors equal weight. A donor meets the joint direction only if adjusted ΔNF exceeds the registered margin and ΔHCM is below its negative. Report both continuous changes, individual donor sample sizes, joint count, leave-one-donor-out range and uncertainty at donor level. Report raw deletion separately. Never replace the joint test with NF minus HCM.
4. **Coverage and independence.** Register the donor universe and exclusions before looking at signs. Count atlas, RNA-detected, token-retained, paired and actually scored nuclei separately. A missing donor is unassessable. Keep training donors, validation donors, untouched test donors and an independent cohort separately labeled. Remove donor caps for exhaustive scoring when feasible; equal donor weights address unequal cell counts. If subsampling is needed, publish its seed and inclusion map.
5. **Replication versus optimization.** Report exact replay, transfer on paired cells and validation on new donors as separate outcomes. A negative transfer result with valid QC is a valid benchmark result. The preferred configuration is the one selected by prespecified validation and declared tolerances. Selecting a checkpoint, axis, control set or margin for its GSN donor count uses the outcome during selection. Assess such a newly developed method on untouched donors and genes. No universally optimal control count, accuracy threshold or donor fraction has been established. [Statistical criteria](../../docs/STATISTICS.md)
6. **DNA evidence.** Check reference sequence, allele direction, repeated calls and valid reciprocal SNVs. Compare independent REF and ALT predictions to the scorer. Retain uncertainty and allele counts for measured eQTLs. Nearby motif-matched edits test local specificity. Declare ascertainment if the selected leads came from the comparison data. A model fold label alone does not show that the locus was held out. Separate expression evidence, embedding response and measured functional rescue. A reference-sequence prediction has no nine-donor denominator. [AlphaGenome scoring](https://www.alphagenomedocs.com/variant_scoring.html)

## Run the scoring fixture

From the repository root, use Python 3.9+ or prefix either command with `uv run --no-project`. All fixture rows are synthetic.

```sh
python3 benchmarks/cardiac-isp/score.py cell benchmarks/cardiac-isp/cohort.tsv benchmarks/cardiac-isp/cell.tsv
python3 benchmarks/cardiac-isp/score.py cis benchmarks/cardiac-isp/alleles.tsv
```

The cell fixture returns one of two donors with both signs. The two donor means give equal-donor ΔNF = 0.125 and ΔHCM = 0.025. The DNA fixture returns two directional loci of three registered, one agreeing. Run each checkpoint, count layer, partition, edit, primary readout and comparator study separately. The cell scorer requires exactly one score per registered paired cell and checks its donor. Supply signed target shifts and the mean signed control shift on each axis. Use zero control columns only for a separately labeled unadjusted run. The DNA input requires one primary observation per locus; use NA for both beta and se when unavailable. Coefficients must be harmonized to the same ALT first. The reported interval is a normal approximation.

The scorer aggregates supplied predictions. It does not train a model, infer eligibility, verify gene identity, perform multiplicity correction or fetch biological data. Retain those upstream checks in the run manifest. Include code and weight hashes, dataset and split, start and goal states, fine-tuned and released baselines, denominator reconciliation, seeds, environment lock and deviations alongside each result. Keep identifiable cells, credentials, study results and restricted manifests in the study's authorized repository.
